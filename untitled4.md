Here's a structured guide to commonly used **multimodal evaluation metrics** in Retrieval-Augmented Generation (RAG) systems, including their descriptions, formulas, examples, and usage scenarios.

---

## 📊 Multimodal Evaluation Metrics Overview

| Metric      | Description                                                                 | Formula                                                                                  | Example                                                                                                                                                                                                                                   | Usage Scenario                                                                 |
|-------------|-----------------------------------------------------------------------------|------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| **CLIPScore**   | Measures semantic alignment between an image and a caption without requiring reference captions. | $$\(\text{CLIPScore}(I, C) = \max(100 \times \cos(E_I, E_C), 0)\)$$                         | *Image*: A cat sitting on a sofa. <br> *Caption*: "A cat lounging on a couch." <br> Compute CLIP embeddings for both and calculate cosine similarity. If similarity is 0.85, then CLIPScore = 85.                                         | Evaluating image-caption alignment in image captioning tasks.                   |
| **VQA Accuracy**| Assesses the correctness of answers in Visual Question Answering tasks, considering human variability. | $$\(\text{Accuracy} = \min\left(\frac{\text{\# of humans that provided the answer}}{3}, 1\right)\)$$ | *Question*: "What is the color of the cat?" <br> *Model's Answer*: "Gray" <br> *Human Answers*: ["Gray", "Grey", "Gray", "Black", "Gray", "White", "Gray", "Gray", "Black", "Gray"] <br> Count of "Gray": 6 <br> Accuracy = 1.0 | Evaluating model performance in Visual Question Answering tasks.               |
| **SPICE**       | Evaluates the semantic content of image captions by comparing scene graphs derived from candidate and reference captions. | Computes F-score over matching tuples (objects, attributes, relations) in scene graphs. | *Candidate Caption*: "A gray cat is sitting on a sofa." <br> *Reference Caption*: "A cat lounges on a couch." <br> Extract scene graphs and compute F-score over matching tuples.                                                         | Assessing semantic content in image captioning.                                |
| **CIDEr**       | Measures the similarity of a generated caption to a set of reference captions using TF-IDF weighting for n-grams. | $$\(\text{CIDEr}(c, S) = \frac{1}{N} \sum_{n=1}^{N} w_n \cdot \text{CIDEr}_n(c, S)\)$$      | *Candidate Caption*: "A gray cat is sitting on a sofa." <br> *Reference Captions*: ["A cat lounges on a couch.", "A gray feline rests on a sofa."] <br> Compute TF-IDF vectors and calculate cosine similarities for n-grams.             | Evaluating consensus in image captioning with multiple references.             |
| **BLIPScore**   | Assesses image-caption alignment using BLIP model embeddings.            | Computes cosine similarity between BLIP embeddings of image and caption.                | *Image*: A photograph of a cat on a sofa. <br> *Caption*: "A gray cat is sitting on a couch." <br> Compute BLIP embeddings and calculate cosine similarity.                                                                               | Evaluating image-caption alignment using BLIP model.                           | ([jmhessel/clipscore: CLIPScore EMNLP code - GitHub](https://github.com/jmhessel/clipscore?utm_source=chatgpt.com), [Evaluating AI-generated images with CLIP Score - Exploring AI](https://unimatrixz.com/blog/latent-space-clip-score/?utm_source=chatgpt.com), [Visual Question Answering — A Deep Learning Classification Case ...](https://medium.com/%40niralidedaniya/visual-question-answering-a-deep-learning-classification-case-study-3d8df1eb48e3?utm_source=chatgpt.com), [Semantic Propositional Image Caption Evaluation (SPICE) - GitHub](https://github.com/peteanderson80/SPICE?utm_source=chatgpt.com), [SPICE: Semantic Propositional Image Caption Evaluation](https://www.panderson.me/spice/?utm_source=chatgpt.com), [[PDF] CIDEr: Consensus-based Image Description Evaluation - Devi Parikh](https://deviparikh.com/publications/CVPR2015_cider_extended_abstract.pdf?utm_source=chatgpt.com))

---

These metrics provide comprehensive tools for evaluating the performance of RAG systems, especially in tasks involving multimodal data such as images and text. Selecting the appropriate metric depends on the specific requirements of the task and the aspects of performance that are most critical to assess.
